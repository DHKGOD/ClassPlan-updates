# 校務 E-Smart / ClassPlan

Windows 校務排課桌面程式的公開更新發布頻道。

## 下載與更新

- 已有「基本設定 → 更新」功能：在程式內檢查更新、下載，再更新並重新啟動。
- 舊版本沒有更新功能：在[最新版發布頁](https://github.com/DHKGOD/ClassPlan-updates/releases/latest)下載 `ClassPlan-Upgrade-版本.exe`，儲存並關閉程式後，選取原本的 ClassPlan 資料夾完成一次升級。
- 全新 Windows 電腦：下載完整 `ClassPlan-Setup-版本-代號.exe`，內含離線 WebView2 執行環境。

更新會保留本機專案、課表、行事曆與提醒資料。每台電腦各自保存資料。

更新資訊與更新包有簽章及 SHA-256 驗證。差異更新只下載變動的程式檔；需要時改用完整程式更新包，不重裝 WebView2。

此儲存庫只發布程式更新，不包含使用者資料或簽章私鑰。
